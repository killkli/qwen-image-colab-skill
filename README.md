# Qwen-Image-2.1 Colab Skill

A standalone agent skill for generating and editing images with Alibaba's Qwen-Image-2.1 through Google Colab.

- [English documentation](README.en.md)
- [繁體中文文件](README.zh-TW.md)

Install into the default Codex skills directory with `./install.sh`. The skill is named `$qwen-image-colab`.
